# Run 7 rule: the valley of Secacah is Naḥal Sekhakha (Wadi Abu Shuʿla)

Fixed 27 Oct 2026 before any new evidence was gathered for this run. **Exploratory, and not independent of run 1**: the model came from run 1's evidence (the shared wadi), so a fit here cannot confirm it. What it can do is fail.

## Model
Sekakah = Kh. es-Samra (Milik 1962's biblical town). "The valley of Secacah" (entries 20, 21) = the whole Wadi Abu Shuʿla / Naḥal Sekhakha drainage, from its head near Har Monṭar to its junction with the Buqeiʿa outlet. Entry 21's "head of the water conduit" = Hyrcania's northern-aqueduct intake (dam 44, Patrich 1989 p. 251).

## Relations (as run 1, with the valley redefined)
- **J1–J7** exactly as in run 1's RULE.md, except: the valley is the whole Wadi Abu Shuʿla channel network upstream of 31.7293 N 35.4134 E (run 1's Samra downstream end), and features count if within 200 m (strict) or 500 m (lenient) of any channel draining ≥0.25 km².
- **J8 (new, can fail):** entries 20–23 are consecutive and all name Secacah. So the cairn (J3), the conduit head (J4), the reservoir with a fissure east of it (J5) and the trench/heap pair (J6) should all lie within one walkable cluster: every pair of the features used within **6 km** of each other along the valley. If the best features for J3–J6 are more than 6 km apart, J8 fails.
- **J9 (new, can fail):** entry 24's "tomb in the Wadi of the Vault (Kippa), on the way from Jericho to Secacah" should lie on a documented route between Jericho and Kh. es-Samra, in a ravine. Candidates: any recorded tomb in a ravine crossed by the Buqeiʿa–Jericho route (Cross & Milik 1956; Patrich 1994; Dorsey 1991). No such tomb recorded = unknown; a route with no ravine = fail.

## Control
The same redefinition applied to **Wadi Qumran** (whole drainage, Kh. Qumran as S), so the bigger valley is not a privilege of the new model. Score both with the same sources.

## Decision
Report pass/unknown/fail for J1–J9 for both, strict and lenient. The model is **damaged** if J8 or J9 fails, and **survives** otherwise. It is **preferred over the control** only if it has more passes and no more fails in both readings. No identification follows either way.
