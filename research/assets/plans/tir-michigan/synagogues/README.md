The full native-resolution 7425 × 10926 JPEG derivative is stored in verified sequential parts. Run `python restore_native.py` in this folder to reconstruct it. Quality 95 JPEG is a derivative, not a byte-identical TIFF. The original 243 MB TIFF is not committed. Bounds and checksums are in [manifest.json](manifest.json).
