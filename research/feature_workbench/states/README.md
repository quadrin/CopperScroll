# Historical feature states

This module implements method 4 with IV/17 and Tell es-Sultan pilots. Run `python3 research/feature_workbench/states/evaluate.py` for the module snapshot or `python3 -m unittest discover -s research/feature_workbench/states -p 'test_*.py'` for its checks.

`register.json` separates recorded architecture, published reconstructions and unknown ancient configurations. `evaluate.py` imports the corrected IV/17 repeat endpoint identities and reviewed dimensions from the existing records. It evaluates nine saved phase, construction, access and threshold claims. Compatibility is exploratory; none is an archaeological identification or a deposit result.

The IV/17 native frame retains crop size, origin, axes, scale, north convention and source/render hashes. Only two existing project aperture chords have geometry. They carry both repeat sensitivity ranges and first-pilot envelopes; these are non-statistical raster sensitivities with additional unquantified systematic error. The southern remaining gap is not a traced pre-wall mouth. Wall and pillar dimensions/relations remain catalog observations without invented polygons. Source images remain rights-qualified links. No source-plan chord is exported as world geometry.

The Hellenistic cave-use reconstruction does not date wall construction, pillar cutting or the northern threshold. The three-cubit vertical branch retains `z_target = z_threshold − depth`, an exploratory unit range and a null ancient datum. It supplies no entrance-width requirement or target point.

At Jericho, D9's Bronze Age shaft and Roman reuse form a recorded sequence. N.S.1 remains a separate unplanned cistern. Kenyon III's phase-lxxvii pits cut phase-lxxvi grave shafts, contradicting a same-stratigraphic-phase assertion. That relation leaves the later opening date, surviving grave access and an entry-60 mouth/grave association unknown. Named excavation phases are local: the Kenyon section ordinates are not geographic coordinates. Plate 111b and the actual eastern section remain uninspected dependencies, as distinct from the now inspected III text.

The historical irregular basin, curved spring-house wall and reservoir built in 1898 retain separate feature IDs. The modern reservoir fails the saved early construction window. Historical photographic observation dates and the tentative late Roman/Byzantine wall opinion do not date the older basin's construction.

For presentation, `data.views` groups state IDs and saved query IDs; `data.transitions` records topology or relative succession; `data.reference_frames` defines the native coordinates. All geographic overlays and world geometries are null. The chronology evaluator accepts source-observed order, rejects cycles and keeps a proposed predecessor from becoming an observed sequence. Contemporaneous accessibility requires its own source-observed relation; order or broad date overlap cannot supply one.

Each saved ancient accessibility query carries a named access-phase context and the exploratory 100 BCE–100 AD comparison window already used for the construction queries. This is an analysis window, not an established Scroll compilation or instruction date. An access record must have an observed relation, already-inspected source references, an explicit attachment to that query phase context, `dating_basis: dated_observed_access_episode`, the historical-year calendar and finite `dated_accessible_interval` bounds wholly within the window. A modern episode, undated statement, broad reconstruction or disjoint date bounds leave ancient access unknown. An observed negative episode also remains unknown unless it explicitly covers the complete named query and entire window; conflicting complete negative and positive records return `mixed`.

All sources were already exposed. This implementation adds no source-inspection count, independent field campaign, unused prediction, confidence value, coordinate, fieldwork or outreach. Missing construction contacts and records are explicit in `data.dependencies`.
