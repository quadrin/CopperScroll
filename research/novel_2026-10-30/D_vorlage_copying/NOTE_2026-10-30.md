# Direction D: copying errors from an ink exemplar (Vorlage) to copper

30 Oct 2026, worker D. Branch `claude/novel-2026-10-30-D`.

**Status:** exploratory method test. No identification claim. No rating, ledger, ACTIVE_TEST or atlas change.

## Question

The engraver may have copied from an ink exemplar. If he did, some unplaced names may be miscopies whose errors follow how ink letters look. The test asks whether emending those names with an ink-hand confusion model recovers real place names more often than chance and more often than control emendations.

## Novelty gate

- No "Vorlage" or copying-error model exists in `main`, `sandbox/methods` or `research/logs/`.
- Earlier work:
  - The edition-confusion matrix compares how modern editors read the copper. It is used here only as a control.
  - T01 (Palmer) and sandbox run 19 (Mandate field names) matched the edition readings, not emendations.
- What is new: an ink-hand model built without using the Copper Scroll, and emendations of the names made before matching.

## Result (confirmatory, run once)

One match unit is a (string, gazetteer family) pair. There are 3 families: Palmer, Mandate and ASI. The chance rate for each unit is the existing one: T01's random-pattern baseline for Palmer, and run 19's C1 shuffle rate for Mandate and ASI.

| Set | Matches | Expected by chance | p (Poisson-binomial) | Palmer / Mandate / ASI |
|---|---|---|---|---|
| **V** (Vorlage), 240 strings | **162** | 131.95 | 2×10⁻⁵ | 21 / 81 / 60 |
| E (edition control), 240 strings | **173** | 135.79 | < 10⁻⁵ | 21 / 93 / 59 |
| Uniform control (10,000 draws) | mean 145.2, 95th percentile 164 | — | — | — |
| Original readings (46 variant cores) | 44 | 29.2 | — | 7 / 20 / 17 |

**What the tests say:**

- **(i) Against chance: passes.** But the edition set and the original readings beat chance by as much or more. So the excess comes from the matching rules and the gazetteers, not from the Vorlage model. Run 19 found the same pattern: its control names from Joshua beat their shuffles as well.
- **(ii-a) Against the edition control: fails.** V-only strings had 11 fewer matches than E-only strings (permutation p = 0.86).
- **(ii-b) Against the uniform control: fails.** p = 0.079.
- **Verdict: not obtained.** The frozen failure condition is met.

**Copper Scroll correction check** (`results/copper_corrections_check.json`):

- Data: 26 of Puech 2015's "engraved X, corrected to Y" letters.
- They fit the edition model better than the Vorlage model. The Vorlage model wins on only 7 of 26 (mean log₂ p_V/p_E = −1.54). It also does worse than uniform (−0.92).
- The engraver's corrected letters are mostly ו/ר (11), נ/ר (4) and ג/א (3). ו/ר is Puech's own "frequent w/r confusion in first-century cursive". Neither Delitzsch's square-script list nor the Habakkuk book hand ranks it high.
- If a Vorlage existed, its hand was probably semi-cursive, not the formal book hand I modelled.
- This check is not a clean holdout: I saw the X(Y) list before freezing.

## Limits

- **Delitzsch** documents medieval MT confusions in the square script, not Herodian ink specifically. I read his pairs from the table of contents, the running heads and the § labels, not from every example.
- **Shape similarity** comes from one modern font tracing of one book hand. No semi-cursive hand was modelled.
- **Qumran corrections** give 72 events, which is sparse.
- **Palmer** was scored only on T01's priority-sheet pool (2,647 records), not on all 9,368, because the existing chance baseline covers only that pool. 187 consonant patterns had no stored baseline and got 200 new random cores each, drawn with T01's own generator.
- **Single substitutions only,** with K = 10 per name.
- **ASI** is the romanised names from `asi_jerusalem`. Hebrew-romanised and English names were excluded under run 19's S3 filters.
- **Run log.** The first launch was killed by the 50-minute tool limit before it wrote anything. The identical frozen code was rerun once; see `results/run_log.txt`.

## Closing line

**Not obtained.**

- Vorlage-weighted emendations beat chance only as much as any emendation set does. They lose to the modern edition-confusion control and do not beat the uniform control.
- The scroll's own corrections fit the edition pattern (ו/ר, נ/ר), not the formal-hand model.
- What changes: emending the unplaced names by ink-hand letter similarity adds no evidence for any of them. The toponymy route stays at chance level, now for emended names as well.
- A second AI-only session is justified only if it models a semi-cursive hand built from the scroll's own ו/ר and נ/ר evidence and is tested against a fresh gazetteer. Without that, it is not justified.
