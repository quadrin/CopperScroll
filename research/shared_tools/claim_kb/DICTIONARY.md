# Record dictionary and maintenance decisions

`schema.json` defines the transport and central payload contracts. `model.validate()` checks that subset of JSON Schema plus graph and evidence invariants. The validator deliberately makes no remote schema requests. All persisted records use `key = kind/id`; `id` preserves the original project ID. This typed address avoids collisions between an existing source ID and an existing task ID. A generated index is never an alternative place to edit evidence.

Every record has `label`, `payload`, `locators`, `review_status`, `exposure` and `visibility`. Locators keep `repo_path`, `pointer`, `printed_page`, one-based `pdf_page`, `figure`, `image_region` and `archival_identifier` separate. An RFC 6901 pointer addresses JSON; CSV uses `/field=value` selectors, including combined score keys. Null means unestablished. A source-index hit or catalogue association supplies no inspection event. A partial inspection uses the existing `already_inspected` vocabulary plus exact `inspection_scope`, `inspected_parts` and `uninspected_parts`; no whole-work inspection is implied. Screen captures may split one printed page across multiple PDF slices, retained without an invented constant offset.

`review_status` is `accepted` in this layer. Automatic extraction proposals belong outside it. `visibility` is `public_metadata`, `local_only`, `restricted` or `reserved`. Source inspection keeps the workbench vocabulary `already_inspected`, `not_inspected`, `derived`. Observation `exposure` retains the inherited vocabulary. Public projections remove protected records and every record dependent on them, transitively. Local HTTP routes resolve only an existing public record's locator; they expose neither arbitrary paths nor image/PDF bytes. Source-note links retain citations rather than exporting whole neighboring notes.

## Text and manuscript location

`entry` adapts the full canonical concordance, edition-specific numbering, division notes and shared-boundary warnings. `locus` holds a logical manuscript line or interval. `segment` holds a physical cut. Their identifiers remain separate. `witness` identifies the original object; `image.substrate` distinguishes original, replica and reconstruction. `image.association_status` and `original_roi` keep catalogue associations separate from authenticated line registration. No original-letter vote enters this pilot.

`reading_set` preserves an existing alternative-reading record and its ID. Individual `reading` records address each edition/candidate string. A reading keeps its author, form, edition locator and witness basis. `interpretation` separately addresses lexical meanings, syntactic attachments, identification opinions and explicit model choices. `restoration` keeps an editorial addition/correction distinct from visible letters. The pilot retains the Puech direction-article correction with an unknown glyph segmentation; it does not fabricate an original-letter observation. Unsegmented braces and uncertain physical boundaries remain explicit gaps. `translation` adapts the existing project translation with its line context.

`branch` holds one retained interpretation or finite choice combination. `requirement` holds a source-derived predicate, subject/object roles, branch applicability and missing-observation condition where available. Workbench Entry 25 requirements depend on the exact branch and its individually addressable dimension interpretations. Koḥlit requirements retain the existing predicate IDs and their branch applicability. Branch-level conclusions have explicit dependency edges to readings, requirements and observations; applicability of one shared predicate template does not spread a changed reading into unrelated branches.

## Names

`name` is a retrieval grouping. `occurrence` is a single located written occurrence, preserving original spelling, language, context and normalized search forms. It separately holds `composition_date`, `object_date`, `period_described`, document/object `findspot`, and `place_mentioned`. Dates use a range and textual dating basis where supplied; null remains null. An approximate compilation date is not a dated manuscript. A recorded phrase containing spelling alternatives stays available as `attested_spelling_as_recorded`; its physical-witness collation remains unresolved.

`entity` is the referent that an occurrence may mention. The scroll's Koḥlit and the Talmud's district have separate entity records and null geographic locations. `identity` records a proposer, evidence, proposed relation and status. `same_spelling`, `proposed_spelling_variant` and `proposed_same_referent` remain different relationships. `merged` must remain false in this bounded pilot. A shared label cannot merge caves, occurrences or proposed referents.

`search` records corpora, queries, spelling variants, inspection scope, result and limitations. `no_external_match` is bounded by that record. The ʿAṣla row preserves a useful unsuccessful search plus an `incomplete_coverage` gap. It supplies no universal absence statement. A documentary search result is never a negative excavation.

## Places and time

`feature` adapts a stable physical identity. `state` records observed, reconstructed or unknown arrangements, phase, source frame and uncertainty. `event` imports the documented construction/blocking/alteration/sequence relationships without adding dates. Generic cave-use dates cannot date a wall, pillar or threshold. A hypothesis's `state_keys` selects one arrangement; demonstrably incompatible accessible intervals cannot form that arrangement. An overlap alone cannot assert coexistence: a compatible coexistence assertion requires its own observation keys.

`frame` retains native plan pixels, scale-bar endpoints, north convention, crop provenance and hashes. Measurements preserve their original value/unit and raw point definitions. Claim `measurement_context` separately names unit, frame, phase, datum, endpoints, reference surfaces, direction convention, coordinate system and uncertainty where recorded. Unestablished fields stay null; the native endpoint string is retained as `point_definition_as_recorded`. `schema.json` also defines an explicit measurement payload for later reviewed extraction. No coordinate conversion, image registration or new digitization occurs here. World geometry requires a documented registration, CRS and uncertainty. XII/53's flagged printed grid remains documentary text, with null world geometry.

## Sources and assertions

`work`, `edition`, `copy` and `source` separate bibliographic identity, edition, digital-copy provenance and the exact reviewed citation/scope. The pilot only normalizes work/copy identities supported by its explicit reviewed mappings; multi-work summaries remain source records. There is no title-based work deduplication. `copy` and `image` keep existing hashes and access/rights metadata. Original PDFs and restricted images retain their established locations.

`observation` preserves each workbench observation ID, feature/property/value, evidence kind, phase, exposure and source references. `lineage` labels an original observation or a weaker campaign/reporting grouping. `reports` edges mean actual reuse of an identified original observation. `same_campaign` does not merge individual observations or prove their independence. Four source/analysis records reuse Sion Plan 5; published 0.8 m aperture width and a derived plan chord remain different quantities.

`claim` has subject, relationship, value, analyst, evidence kind, status, historical/measurement context, separate reading confidence, site association, feature identity, positional uncertainty and supersession references. Missing uncertainty dimensions remain null. Supporting/conflicting/prerequisite claims use typed edges. Existing evidence kinds stay `observed`, `published_reconstruction`, `excavator_label`, `textual_constraint`, `inference`. Claim predicate vocabulary comes from the reviewed workbench and is enumerated in the schema. The 15 October source follow-up adds `proposed_feature_identity` for a documented, unmerged crosswalk and `source_inspection_scope` for a bounded page-inspection result; neither is an archaeological absence predicate. `published_cavity_characterization` preserves an attributed natural-cavity description with explicit scope uncertainty; it cannot negate a separately reported built wall. The 19 October 2026 Kallai update adds `reported_form` for a source's description of a feature's form (for Kallai's pool: a water pool with remains of its roofing vault, not called rock-cut); it is a description, not a measurement. Source counts and graph connectivity generate no confidence score.

`hypothesis` assigns textual roles to fixed feature IDs. Null roles stay unassigned. `evaluation` is a derived branch-specific claim with its exact hypothesis, branch, window, checks, sources and fixed assignment. Every check must use that assignment. Changing a pool, mouth, wall or origin requires a separate hypothesis/version. Results keep `compatible`, `contradicted`, `unknown`, `mixed`, `info`; compatibility stays exploratory. `identification_support` is false throughout the migrated pilot.

## Tests and revision

`test` holds the exact selected claim/specification, retained branches, candidate/control roster, decision rule and scope. The pilot distinguishes its original three-cave workbench from the frozen regional comparison. It preserves the full regional roster in test metadata and materializes only five selected regional controls. Saved phase tests and the separation-planning snapshot remain historical records. Frozen commit/specification pointers do not certify an unused observation.

`coverage` preserves target, survey/excavation reach, datum, phase, disturbance and detection obligations in their original record types. Documentary silence requires a recorded search scope. Archaeological absence additionally requires the original target-volume/detection gates. This pilot creates neither an absence claim nor a detection probability.

`gap.reason` uses `uninspected_source`, `insufficient_resolution`, `uncertain_phase`, `missing_reference_point`, `incomplete_coverage`, `unverified_identity`, `unregistered_image`, `unsegmented_editorial_layer`, `not_recorded`, `unestablished_geometry` or `unverified_independence`. Gaps carry unknowns, never false observations. `acquisition` holds an exact target, exposure/freeze gates and conditional outcomes marked `actual_observation=false`. Each outcome has `recorded=false` unless the task's `recorded_outcome` names it with its record files (Kallai pp. 172–173, 19 October 2026). `would_resolve` links it to the affected claim, branch or gap.

SQLite snapshots preserve records, edges, parent version, base commit and every input hash. `depends_on`, `derived_from`, `cites`, `reports`, `supports`, `conflicts`, `prerequisite`, `evaluates`, `under_branch`, `in_test`, `interprets`, `state_of`, `uses_frame` and `same_campaign` form a conservative reverse dependency graph. Hash drift blocks current queries; changed evidence carries persistent reassessment flags after rebuilding. Explicit reviewed acknowledgments can resolve those flags. Historical values and input versions remain queryable. Revisions never erase the prior scientific test result.

These source, state/event, attribution and derivation distinctions follow established archaeological/provenance modelling practice. The pilot makes no claim of full ontology conformance and adds no graph server.

Explicit source-review notices may set `claim.reassessment_required=true`. The public exporter follows the same dependency rules to label affected historical evaluations, with their exact trigger keys. Clear that notice only after updating the canonical assessment and documenting the review; a generated snapshot or a new source copy cannot clear it. This keeps the public alert reproducible without exporting local SQLite history.
